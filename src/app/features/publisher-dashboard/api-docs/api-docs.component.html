Partner API Reference

Complete reference for the Nexus Offerwall Server-to-Server API. All endpoints require Basic Authentication using your ApiKey and ApiSecret.

S2S Authentication

All server-to-server requests use HTTP Basic Authentication. Concatenate your ApiKey and ApiSecret with a colon, Base64-encode the result, and pass it as the Authorization header.

HTTP Header Format 
Authorization: Basic Base64(ApiKey:ApiSecret)

🔑 ApiKey (Public)

Identifies your partner account. Format: pk_live_...

🔐 ApiSecret (Private)

Authenticates your request. Format: sk_live_... — never expose client-side.

Coupon Redemption API

Validates and atomically redeems a user coupon code. A coupon can only be redeemed once. Always call from your server backend — never from client-side code.

POST
/api/partner/coupons/redeem
REQUEST BODY application/json 
{
  "code": "CPN-A1B2C3D4"
}
RESPONSE 200 OK 
{
  "couponId":    "018f3a5b-...",
  "code":        "CPN-A1B2C3D4",
  "usdValue":    10.00,
  "userId":      "018f3a5b-...",
  "countryCode": "EG",
  "status":      "Redeemed",
  "createdAt":   "2026-10-28T12:00:00Z",
  "redeemedAt":  "2026-10-28T12:05:00Z"
}
Important: Use usdValue as the discount amount to apply in your checkout. Only apply the discount after receiving a 200 OK response. The redemption is atomic — each code can only be used once.

Error Codes

All errors follow RFC 7807 ProblemDetails format with a detail and extensions.code field.

Error Response Shape 
{
  "type":   "https://tools.ietf.org/html/rfc7807",
  "title":  "Coupon.AlreadyRedeemed",
  "status": 409,
  "detail": "This coupon has already been used.",
  "extensions": { "code": "Coupon.AlreadyRedeemed" }
}
Status Code Meaning Action
401 Partner.Unauthorized Invalid ApiKey or ApiSecret Check credentials in Integration settings
400 Coupon.InvalidCode Request missing the code field Ensure body includes "code"
404 Coupon.NotFound Code not found or wrong partner Verify the coupon belongs to your store
409 Coupon.AlreadyRedeemed Coupon was already used Do not apply discount
409 Coupon.Cancelled Coupon was cancelled by user Inform user — coupon invalid
410 Coupon.Expired Coupon passed its expiry date Inform user — coupon expired

Webhooks (Postbacks)

When a user completes an offer, Nexus sends a real-time server-to-server postback to your configured endpoint with the conversion details.

Postback Parameters

Parameter Type Description
offer_idstringUnique identifier of the completed offer
user_idstringYour end-user identifier
amountdecimalUSD value of the conversion
currencystringAlways USD
transaction_idstringUnique transaction ID (use for dedup)
statusstringcompleted or chargeback
timestampISO 8601UTC time of the event
