Server-to-Server Coupon Redemption API

Integrate coupon validation directly from your backend using Basic Authentication.

1

Authentication — Basic Auth Header

Encode your credentials as Base64(ApiKey:ApiSecret) and pass them in the Authorization header.

# Build the credential string
CREDENTIAL="$(echo -n '<ApiKey>:<ApiSecret>' | base64)"

# Example HTTP header
Authorization: Basic ${CREDENTIAL}
2

Endpoint

POST https://winfloos.runasp.net/api/partner/coupons/redeem
3

Request Example

POST /api/partner/coupons/redeem HTTP/1.1
Host: winfloos.runasp.net
Authorization: Basic <Base64(ApiKey:ApiSecret)>
Content-Type: application/json

{
  "code": "CPN-XXXXX"
}
4

Success Response 200 OK

{
  "couponId": "3fa85f64-...",
  "code": "CPN-XXXXX",
  "usdValue": 5.00,          // Discount amount to apply in USD
  "userId": "...",            // Your end-user's ID
  "countryCode": "EG",
  "status": "Redeemed",
  "createdAt": "2026-10-28T...",
  "redeemedAt": "2026-10-28T..."
}

Use the usdValue field to determine how much discount to apply in your checkout. Only apply the discount after receiving a 200 OK response.

5

Error Codes Reference

HTTP Status Error Code Meaning
401 Partner.Unauthorized Invalid ApiKey or ApiSecret
404 Coupon.NotFound Code not found or belongs to a different partner
409 Coupon.AlreadyRedeemed Coupon was already used — do not apply discount
409 Coupon.Cancelled Coupon was cancelled by the user
410 Coupon.Expired Coupon has passed its expiry date
400 Coupon.InvalidCode Request body missing the code field

Security Best Practice

Always call this endpoint from your server backend only. The ApiSecret must never be embedded in browser JavaScript, mobile apps, or any client-side code. The redemption is atomic and idempotent — a coupon can only be redeemed once.
